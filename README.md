## ขั้นตอนติดตั้ง (ทำครั้งเดียว ใช้เวลา ~10 นาที)

### 1. สร้างบอท Telegram
1. เปิดแชทกับ [@BotFather](https://t.me/BotFather) ใน Telegram
2. พิมพ์ `/newbot` ตั้งชื่อบอท จะได้ **Bot Token** มา (เก็บไว้)
3. ส่งข้อความอะไรก็ได้คุยกับบอทของคุณ 1 ครั้ง (สำคัญ ต้องทำก่อนขั้นต่อไป)
4. เปิดลิงก์นี้ในเบราว์เซอร์ (ใส่ token ของคุณแทน `<TOKEN>`):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   จะเห็นตัวเลข `"chat":{"id": ...}` นั่นคือ **Chat ID** ของคุณ

### 2. สร้าง GitHub repository
1. ไปที่ [github.com](https://github.com) → สร้างบัญชี (ถ้ายังไม่มี) → New repository
   ตั้งชื่ออะไรก็ได้ เช่น `signal-desk-bot` เลือก **Private** ก็ได้
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (ลากไฟล์วางในหน้าเว็บ GitHub ได้เลย
   ต้องคงโครงสร้างโฟลเดอร์ `.github/workflows/signals.yml` ไว้ตำแหน่งเดิม)

### 3. ใส่ Secrets (เก็บ Token อย่างปลอดภัย ไม่โชว์ในโค้ด)
ใน repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
เพิ่ม 2 ตัว:
- `TELEGRAM_BOT_TOKEN` = Bot Token จากขั้นตอน 1
- `TELEGRAM_CHAT_ID` = Chat ID จากขั้นตอน 1

### 4. เปิดใช้งาน Actions
1. ไปแท็บ **Actions** ของ repo → กด "I understand my workflows, go ahead and enable them"
2. เลือก workflow **ชี้ช่องรวย by โค้ชต้น - Signal Bot** → กด **Run workflow** เพื่อทดสอบรันครั้งแรกด้วยมือ
3. เช็ค Telegram — ถ้ามีสัญญาณเข้าเงื่อนไขตอนนั้นจะมีข้อความส่งมา (ถ้าไม่มีสัญญาณ
   ณ ขณะนั้นจะไม่มีข้อความ ซึ่งปกติ ลองดู log ในแท็บ Actions ว่ารันผ่านไม่มี error)

จากนั้นระบบจะรันอัตโนมัติทุก 15 นาทีตลอด 24 ชั่วโมงตามไฟล์
`.github/workflows/signals.yml` โดยไม่ต้องทำอะไรเพิ่ม

## ปรับแต่งได้
เปิดไฟล์ `signal_bot.py` แก้ค่าที่ด้านบนไฟล์ได้เลย:
- `INSTRUMENTS` — เพิ่ม/ลบ/เปลี่ยนสัญลักษณ์ที่ติดตาม
- `EMA_FAST`, `EMA_SLOW`, `EMA_TREND`, `RSI_LEN`, `ATR_LEN`, `ADX_LEN` — ปรับพารามิเตอร์อินดิเคเตอร์
- `ADX_THRESHOLD` — ค่ายิ่งสูง ยิ่งกรองเข้มงวด (เข้าเทรดเฉพาะตลาดที่มีเทรนด์ชัดมากๆ) ค่าเริ่มต้น 20 เป็นค่ามาตรฐานที่ใช้กันทั่วไป
- `SL_ATR_MULT`, `RR` — ปรับระยะ SL และอัตราส่วน TP:SL
- `INTERVAL` — เปลี่ยน timeframe แท่งเทียน (`5m`, `15m`, `1h`, ...)
- ความถี่การรัน — แก้ cron ในไฟล์ `.github/workflows/signals.yml`
  (บรรทัด `cron: "*/15 * * * *"`)
